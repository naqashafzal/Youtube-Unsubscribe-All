# YouTube Unsubscribe Manager

A CSP-safe Tampermonkey userscript that helps you manage and bulk-unsubscribe from YouTube channels directly from the YouTube subscriptions page.

Created by **Naqash Afzal**  
Website: **https://www.nullpk.com**

---

## Features

- Bulk unsubscribe from YouTube channels
- Dry-run mode for safe testing
- Test Scan button to detect channels before running
- Pause and Stop controls
- Skip channels by keyword
- Random delay between actions
- Safer confirmation before real unsubscribe mode
- CSP-safe interface with no `innerHTML`
- Footer credit included in the panel
